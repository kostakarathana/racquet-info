# Racquet

Racquet is a free 3D tennis game for Chrome. Play solo offline or challenge a friend on the same Wi-Fi. Multiplayer needs an internet connection to find the other player. Open it from the toolbar or expand into a fullscreen game window.

This repository contains Racquet's public terms, privacy policy and support information. It does not contain the game's source code or assets.
